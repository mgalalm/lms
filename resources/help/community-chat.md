---
title: Using Community chat
category: Community
audience: all
order: 1
---

**Community** is where teachers and students message each other directly, and where group channels (like class-wide announcements) live.

- Every teacher/student pairing gets its own direct channel automatically once a session is scheduled between them.
- Messages support rich text — bold, italics, lists, code blocks — and file attachments.
- New messages arrive in real time; you don't need to refresh the page.
- Teachers can send a **Task** card in a student's channel to assign homework directly in the chat, instead of a separate assignments area.
