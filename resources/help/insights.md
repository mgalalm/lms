**Insights** is your performance scorecard, covering a date range you control (defaults to the last 30 days, with quick presets or a custom From/To range).

- **Top metrics** — objections, flags, excuses, and study level for the period.
- **Attendance** — how often you checked in and joined sessions on time versus late.
- **Performance Insights** — a category breakdown (Feedback, Attitude, Preparation, Curriculum, Teaching, Setup) rolling up into a Total Score.
- **Flags** — each reviewed session gets a 😊 (green), 😐 (yellow), or 😟 (red) flag from admin review. Hover a flag to see what it means, or use the filter buttons to see only sessions with a specific flag.

Reviewed sessions below the summary link back to the actual lesson and student, so you can see exactly which session a flag or score came from.
