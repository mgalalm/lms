# Features

## Core Platform
- **Zoom integration** — Zoom is the core facility used for delivering lessons/live classes. Every "Join"/"Join Now" button across the platform (student home, teacher Next Session bar, teacher Sessions Schedule) opens the session directly in **Zoom** — confirming Zoom is the actual video backend, not just a stated integration.

## Dashboards
- **Teacher Dashboard** — dedicated dashboard for teachers to manage their classes. See [Teacher Dashboard](./05-teacher-dashboard.md).
- **Student Dashboard** — dedicated dashboard for students to access their learning, sessions, and account info. See [Student Dashboard](./04-student-dashboard.md).
- **Login to Dashboard** — direct deep link/button provided via email for quick access to the dashboard.

## Session Management
- **Teacher reassignment** — students can be assigned a new teacher for an upcoming session; system notifies them with the new teacher's name and background.

See also: [Overview](./01-overview.md), [Notifications](./03-notifications.md)
